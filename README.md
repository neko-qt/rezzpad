# Rezzpad

Pure C + GTK3 Notepad clone. It edits text without eating a gigabyte of RAM. That's literally the whole feature list.

I got tired of modern editors requiring an entire WebBrowser engine and 600MB of RAM just to edit a text file, so I made this.

## Features

- ~20MB RAM on startup
- Pure C + GTK3
- Open / Save / Save As
- Native GTK File Dialogs
- Undo / Redo history
- Line / Column counter

## Dependencies

You only need `gcc` and `gtk3` development headers.
